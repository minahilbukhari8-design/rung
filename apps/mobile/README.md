# RUNG mobile app (Expo)

Customer app for Android and iOS. Expo SDK 58, Expo Router, English and Urdu (right-to-left).

Screens: home (occasions, DEMO products and services), search (Roman Urdu works), product, service with booking request, cart and checkout (address, delivery date and slot per shop, test payment / cash on delivery / bank transfer), account with orders and bookings, order and booking detail (cancel, pay advance with test payment).

Login tokens are kept in the phone's secure storage (Keychain on iPhone, Keystore on Android). Payments in this build are **sandbox only**.

## Run it

```bash
pnpm install
# API on your computer (see apps/api), reachable from the phone on your Wi-Fi:
EXPO_PUBLIC_API_URL=http://<your-computer-ip>:4000 pnpm --filter @rung/mobile start
```
Scan the QR code with Expo Go (Android) or the Camera app (iPhone).

## Checks

```bash
pnpm --filter @rung/mobile typecheck
pnpm --filter @rung/mobile test        # unit tests: API client, token refresh, dates, translations
pnpm --filter @rung/mobile test:e2e    # web build of the app on a phone viewport against the real API + Postgres
```

## Store builds (needs accounts)

`eas.json` has `preview` (Android APK to share for testing) and `production` profiles. Building needs a free Expo account; publishing needs a Google Play developer account (one-time USD 25) and an Apple Developer account (USD 99/year). API URLs in `eas.json` are placeholders until the API is deployed.

`android/` and `ios/` are generated by `npx expo prebuild` and are not committed.
